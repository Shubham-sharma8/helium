# Security Policy

## Reporting a Vulnerability

If you discover a security issue in Helium (especially relating to OAuth 2.0 PKCE handling, Keychain storage, or the `OrbitCore.ZK` `AES-256-GCM` encryption layer), please report it privately to **`connect@cogify.me`** rather than opening a public issue.

We will acknowledge your report within 48 hours and coordinate a fix and disclosure timeline.
